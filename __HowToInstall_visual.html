Easy Installation Guide

Welcome! Let's get this mod working in just a couple of simple steps.

Step 1: Find Your Fallout 76 Folder

First, we need to navigate to your user documents folder for Fallout 76.

The Easiest Way:

  1. Press the WINDOWS Key + R Key at the same time to open the "Run" window.
  2. Copy and paste the following path into the box:
%userprofile%/Documents/My Games/Fallout 76/
  1. Press OK. A folder should open containing files like Fallout76.ini and Project76.ini.

Heads Up! The files we are looking for end in .ini, not .txt. You can open and edit them with the standard Notepad app.

Step 2: Add the Magic Lines

Now we'll edit the configuration file to activate the mod.

  1. Look for a file named Fallout76Custom.ini or Project76Custom.ini.
  2. If you don't have this file, no problem! Right-click inside the folder, select New -> Text Document, and name it Fallout76Custom.ini. (Make sure to change the ending from .txt to .ini!)
  3. Open the file and paste the following lines inside:
[Archive]
sResourceIndexFileList=BetterFishing.ba2
bInvalidateOlderFiles=1
sResourceDataDirsFinal=

You're all set!

Just save the file, close it, and you're good to go. Happy fishing!
